Section 1

What the exam covers

The exam is split into skill areas. The percentage shows roughly how much of the exam each area makes up, so spend your time to match.

Manage Azure identities and governance20–25%
  • Manage Microsoft Entra users and groups
  • Manage access to Azure resources
  • Manage Azure subscriptions and governance
Implement and manage storage15–20%
  • Configure access to storage
  • Configure and manage storage accounts
  • Configure Azure Files and Azure Blob Storage
Deploy and manage Azure compute resources20–25%
  • Automate deployment with ARM templates or Bicep files
  • Create and configure virtual machines
  • Provision and manage containers in the Azure portal
  • Create and configure Azure App Service
Implement and manage virtual networking15–20%
  • Configure and manage virtual networks
  • Configure secure access to virtual networks
  • Configure name resolution and load balancing
Monitor and maintain Azure resources10–15%
  • Monitor resources in Azure
  • Implement backup and recovery
Section 2

Key concepts, explained simply

These are the ideas that come up again and again. Open each one and make sure you could explain it to a friend.

RBAC scope

Role assignments combine a security principal, a role definition and a scope (management group, subscription, resource group or resource). Assign at the narrowest scope that works, and remember Owner can grant access while Contributor cannot.

Storage access

Prefer Microsoft Entra ID and RBAC for data access. Shared access signatures (SAS) give time-limited, scoped access; account keys give full access and should be rotated and protected.

VM availability

Availability sets protect against rack failures in one datacenter. Availability zones protect against a whole datacenter failing. Scale sets add or remove identical VMs automatically.

Network security

Network security groups filter traffic by port and IP. VNet peering connects networks privately. Azure Bastion gives secure RDP/SSH without public IPs on your VMs.

Load balancing

Azure Load Balancer works at layer 4 (TCP/UDP). Application Gateway works at layer 7 (HTTP) and can include a web application firewall.

Backup and monitoring

Recovery Services vaults store VM and file backups. Azure Monitor collects metrics and logs, and alerts can trigger action groups such as email or automation.

Section 3

Study plan

About an hour a day is enough. Adjust the pace to your experience.

  1. Week 1–2Identity and governance: Entra ID, RBAC, Azure Policy, locks and cost management. Practise in a free subscription.
  2. Week 3Storage: accounts, redundancy, SAS, Azure Files and Blob lifecycle rules.
  3. Week 4–5Compute: VMs, scale sets, App Service, containers, ARM and Bicep deployments.
  4. Week 6Networking: VNets, NSGs, peering, DNS and load balancers.
  5. Week 7Monitoring and backup, then practice assessments and labs until consistently above 80%.
Section 4

Exam tips

  • Read every question twice. Many answers are “which service fits this scenario”.
  • Use the free practice assessment on Microsoft Learn until you score 80% or more.
  • Hands-on practice beats memorising: build what you read about in a free account.
  • Skip hard questions and come back. Unanswered questions score zero, so answer everything.
  • Check the official study guide a week before your exam in case the skills changed.
