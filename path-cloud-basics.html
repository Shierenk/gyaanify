Lesson 1 of 42 min read

What is the cloud?

The cloud means using computers, storage and software that live in someone else's data centre and are delivered over the internet. Instead of buying servers, you rent exactly what you need and pay for what you use.

You already use the cloud every day: email, photo backups and streaming all run on it. For businesses, the cloud makes it possible to launch quickly, scale up when traffic grows and scale back down when it doesn't.

Key takeaways

  • The cloud is rented computing over the internet
  • You pay for what you use
  • It scales up and down on demand
Practice check

What best describes cloud computing?

Lesson 2 of 42 min read

IaaS, PaaS and SaaS

Cloud services come in three main models. Infrastructure as a Service (IaaS) gives you virtual machines and networks, and you manage the operating system and apps. Platform as a Service (PaaS) gives you a ready platform to run your code, and the provider manages the servers. Software as a Service (SaaS) is a finished app you simply use, like email or a video-call tool.

The further you move from IaaS to SaaS, the less you manage yourself and the less control you have.

Key takeaways

  • IaaS: you manage the most
  • PaaS: you bring the code
  • SaaS: you just use the software
Practice check

You want to run your own code without managing servers. Which model fits best?

PaaS gives you a ready platform for your code while the provider manages the servers.

Lesson 3 of 42 min read

Regions and availability

Cloud providers run data centres in many regions around the world. Choosing a region close to your users makes your app faster and can help with data rules about where information must be stored.

Inside a region, availability zones are separate data centres with their own power and networking. Spreading an app across zones keeps it running even if one data centre has a problem.

Key takeaways

  • Pick a region close to your users
  • Zones protect against data-centre failures
  • Location can matter for data rules
Practice check

Why spread an app across availability zones?

Availability zones are separate datacenters in a region, so one failure doesn't take the app down.

Lesson 4 of 42 min read

Start learning Azure for free

Microsoft Learn offers free, official learning paths with hands-on sandboxes, so you can practise without paying. A good first goal is Azure Fundamentals (AZ-900), which covers cloud concepts, core services, security and pricing.

Study a little every day, build one small project, such as hosting a static website, and write down what you learned. Practising is what makes the concepts stick.

Key takeaways

  • Microsoft Learn is free and official
  • AZ-900 is the best first certification
  • Build a small project as you learn
Practice check

What is a good first Azure certification?

AZ-900 Azure Fundamentals covers cloud concepts and core Azure services, and needs no prior experience.
